# TaskFlow - умный список дел

Программа для управления повседневными задачами: расставляет приоритеты, следит за сроками, выделяет горящие дедлайны.


## Стек
- Python 3.14
- Tkinker (для GUI)
- JSON (для хранения)


## Команда
- **[П П]** - тимлид, GUI, сборка, фишки
- **[Г М]** - модель задачи, сортировка, приоритеты ('task.py')
- **[П С]** - хранение, фильтры, статистика('storage.py', 'filters.py')

``` json

}
